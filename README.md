# Data-Structures-and-Algorithms

A comprehensive collection of 6 academic projects focused on algorithmic efficiency and data structures developed during my studies at Wrocław University of Science and Technology.

## Repository Structure

### 1. [Basic Data Structures](./01-basic-data-structures)
Fundamental building blocks including dynamic arrays and various linked list implementations. (Collaborative)

### 2. [Priority Queues Comparison](./02-priority-queues-comparison)
Performance study of priority queues using different underlying data structures (Array vs. Heap). (Collaborative)

### 3. [Hash Tables Analysis](./03-hash-tables-comparison)
Advanced collision resolution techniques (Cuckoo, AVL-chaining) with analysis. (Collaborative)

### 4. [Sorting Algorithms Analysis](./04-sorting-algorithms-analysis)
Deep dive into comparison-based and distribution-based sorting methods: Quick, Merge, and Bucket Sort.

### 5. [Dijkstra Algorithm Study](./05-graph-algorithms-dijkstra)
Graph traversal optimization comparing Adjacency Matrix and Adjacency List representations.

### 6. [Tic-Tac-Toe AI](./06-tictactoe-minimax-ai)
Implementation of the Minimax algorithm with Alpha-Beta pruning in Tic-Tac-Toe game.

---
*Note: Projects 1-3 were developed as part of a team collaboration. Projects 4-6 are individual implementations.*
